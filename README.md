# Leone DiCamp — Portfólio

Portfólio profissional de **Leone DiCamp**, desenvolvedor focado na criação de sites, sistemas personalizados e automações para negócios.

O projeto apresenta trabalhos reais, projetos-conceito e soluções digitais desenvolvidas para diferentes segmentos.

## Sobre

Desenvolvo soluções digitais sob medida para empresas, profissionais e negócios locais.

### Principais serviços

- Sites institucionais
- Landing pages
- Sistemas web personalizados
- Plataformas de pedidos e delivery
- Sistemas para eventos
- Automações
- Chatbots e atendimento via WhatsApp
- Integrações com APIs e serviços externos

## Projeto em destaque

### Underground RJ

Plataforma desenvolvida para um evento automotivo, com recursos como:

- Venda de ingressos online
- Checkout integrado
- Ingressos digitais com QR Code
- Integração com banco de dados
- Edge Functions
- Processamento e reprocessamento de operações
- Envio automatizado de e-mails

O Underground RJ é apresentado no portfólio como um dos principais cases de desenvolvimento completo.

## Projetos-conceito

O portfólio também apresenta demonstrações e conceitos de soluções para diferentes segmentos, incluindo:

- Restaurantes e lanchonetes
- Clínicas e consultórios
- Profissionais autônomos
- Empresas locais
- Eventos

Esses projetos demonstram possibilidades de aplicação de sistemas, sites e automações desenvolvidos sob medida.
